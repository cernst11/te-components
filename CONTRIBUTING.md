# Contributing

Thanks for helping! Issues and pull requests are welcome.

## Before you start

- Read `DESIGN.md` (visual rules, agreed with the maintainer) and `AGENTS.md` (architecture, gotchas).
- `npm install && npm run dev` starts the playground with a mock Home Assistant; `/check.html` checks every
  card against HA's card-picker contract. `npm run build` must pass.
